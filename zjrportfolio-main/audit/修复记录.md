## 二、已完成的修改

### 1. 图片

- 8 张 PNG 转成 WebP（Pillow，q82），保持 3:2 / 2:3 比例。
- `portfolio/data.json` 中所有封面/肖像路径改为 `.webp`。
- 原 PNG 备份到仓库外的 `audit/original-images/`，并从 `portfolio/public/images`、`portfolio-spa/images` 移除。
- 新增 `og-cover.jpg`（1200×630，95 KB）用于社交分享。
- 作品卡封面 `loading="lazy" decoding="async"`；案例页“更多作品”小图 `eager`；Showreel `fetchpriority="high"` 并预加载。

### 2. 案例页与播放器

- 修复全栈版案例页封面裂图：`#playerPoster` 现在会设置 `src`、`fetchpriority` 和具体 alt。
- 无视频时不再提示“登录后台”，改为“视频正在整理中，可邮件联系获取完整成片”。
- 无视频时隐藏播放器控制条，避免点击无效进度条。
- 进度条支持 `role="slider"`、`tabindex="0"`、方向键 / Home / End；同步 `aria-valuenow`。
- 案例页“点击播放 · 静音循环预览”改为真实状态文案。

### 3. SPA 导航

- 直接打开 `#case=...` 时不再先渲染首页，案例页图片从 12 个降到 4 个。
- 案例 A → 案例 B 会回到页面顶部。
- 返回首页时恢复站点标题，不再停留在上一个案例标题。
- 离开案例页时暂停隐藏视图里的 `<video>`，避免音频继续播放。
- 修复 `#/` 作为 `querySelector` 参数抛异常的问题。
- 移动菜单补 `aria-expanded` / `aria-controls`，支持 Escape/点击外部关闭。

### 4. SEO / 无 JS

- 构建时生成 `<title>`、description、canonical、OG、Twitter、theme-color、Person JSON-LD。
- 服务端按首页/案例页生成对应 title、description、canonical、OG、`WebPage` JSON-LD。
- 新增 `<noscript>` 摘要：姓名、职位、两段简介、6 部作品、邮箱/所在地；无 JS 时隐藏空壳应用，只显示摘要。
- 新增 `robots.txt`、`sitemap.xml`、`404.html`；`/admin` 加 `X-Robots-Tag: noindex, nofollow`。
- 首页 H1/正文在 JS 执行后正常渲染；无 JS 时由摘要提供内容。

### 5. 安全与缓存（全栈版）

- 安全响应头：CSP、`X-Frame-Options: DENY`、`Referrer-Policy`、`Permissions-Policy`、`frame-ancestors 'none'`。
- `X-Forwarded-For` 只在 `TRUST_PROXY=1` 时信任，且取最后一个地址；未开代理时伪造 XFF 不再绕过限流。
- 登录失败记录定期清理并限制上限；改密码时清空所有会话。
- 启动日志不再打印密码；`auth.json` 尝试设为 0600；登录页不再写“初始密码 admin123”。
- malformed JSON 返回 400（不再 500 泄露解析细节）；500 返回通用文案，详细错误只写服务端日志。
- 静态资源加 `ETag` / `Last-Modified`，支持 304；文本资源支持 gzip。
- 图片缓存从 1 天改为 7 天，并配合 ETag；HTML/CSS/JS 保持 no-cache。
- 新增 `SITE_URL`、`TRUST_PROXY` 环境变量说明。

### 6. 可访问性

- `--text-3` / `--text-4` 提亮到 WCAG AA；9–11px 小字统一上调。
- 作品卡移除 `<a>` 内嵌 `<button>`，播放图标改为装饰性 `.play-badge`。
- 视频弹窗补 `role="dialog"`、`aria-modal`、焦点陷阱、关闭后焦点回归。
- 新增跳转主内容链接、`:focus-visible` 焦点样式、打印样式。
- `prefers-reduced-motion` 时数字滚动直接显示最终值。
- 修复不支持 IntersectionObserver 时 `.reveal` 永久隐藏的降级 bug。
- 手机端“擅长方向”卡片增加 `.spec-body` 包裹，修复标题被压成竖排的问题。
- 修复 `<img src="">` 重复请求页面的问题。
- 联系邮箱改为可点击 `mailto:`，主题预填；电话为空时不显示假号码；社交为 `#` 时整块隐藏。

### 7. 其他

- 全栈版与 SPA 的技能条统一使用 `--w`，入场动画一致。
- `build_static.py` 修复动态案例链接替换；补齐基础 meta/预加载/noscript。
- `README`、`DEPLOY`、`GITHUB`、`SYNC`、`.env.example` 同步 WebP、`SITE_URL`、`TRUST_PROXY`、密码与图片体积说明。

## 三、仍需你处理

1. **视频仍为空**（最重要）。Showreel + 6 部作品的 `video` 没有文件；现在的 UI 会礼貌提示“视频整理中”，但作品集仍需要真实视频。
2. **肖像/封面是 AI 生成图**，右下角有“AI生成 / WORKBUDDY”水印。建议换成真实照片和成片截帧；我没有擅自裁掉水印。
3. **Google Fonts 仍是外部依赖**（字体 CSS 459 KB 解码后）。要彻底解决国内可达性和体积，需要自托管 Noto Sans SC 子集或改用系统字体。
4. **没有做完整 SSR/预渲染**。无 JS 摘要和 meta 已补齐，但正文仍由 JS 渲染；如需百度完整收录，下一步应在构建时预渲染首页与每部作品页。
5. **5 部作品没有案例详情**，仍使用“完整案例拆解可在沟通时展示”的通用文案。
6. **上传图片未自动压缩**。后台仍接受 10 MB 图片原样落盘，后续换图可能重新变重。
7. **国内托管**。线上仍是 GitHub Pages；建议自定义域名 + Cloudflare Pages / 国内 CDN，并去掉 Google Fonts 依赖。
8. **CI 与内容检查**。`--strict` 只查媒体存在，不查视频为空、社交为 `#`；建议加 GitHub Actions 和占位内容检查。
