发布上线

把当前内容构建成静态站并推送到 GitHub main。构建会更新根目录 index.html；推送完成后 GitHub Pages 约 1 分钟更新。

一键发布

点击发布会先自动保存当前修改，再构建并推送。需要本机已登录 GitHub CLI（gh auth status）。

它会做什么

1. 运行 python scripts/build_spa.py --strict，把 data.json、CSS、JS 和图片内联/镜像到静态站。
2. 通过 GitHub API 更新 main 分支。
3. GitHub Pages 自动重建，约 1 分钟后线上生效。

视频和大图建议使用外链；GitHub 单文件上限 100MB。
